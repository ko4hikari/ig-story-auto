# 休業日スプレッドシートの作り方

## 方法A: CSV をインポート（5分）

1. [Google スプレッドシート](https://sheets.google.com) を開く → **空白** を作成
2. **ファイル → インポート → アップロード** で `templates/closed_days_sheet.csv` を選択
3. インポート設定: **現在のシートを置換** → インポート
4. **B列（種別）にプルダウンを設定**（必須）
   - B2 セルを選択 → **データ → データの入力規則**
   - 条件: **リストを直接指定**
   - 値: `オープンのみ停止,全停止`（カンマ区切り）
   - **範囲に適用**: B2:B1000（または B:B 全体）
5. **ファイル → 共有 → ウェブに公開**
   - リンクの種類: **コンマ区切りの値 (.csv)**
   - シート: 対象シート（通常「シート1」）
   - **公開** をクリック
6. 表示された URL をコピー → GitHub Secret `CLOSED_DAYS_CSV_URL` に設定

### 緊急停止

シートの **A1 セル** に `PAUSE` と入力すると、日付に関係なく全スロットが停止します。

## 動作確認

```powershell
cd ig-story-auto
$env:CLOSED_DAYS_CSV_URL = "（公開CSVのURL）"
python post_story.py --check
```

休業日行に `open:休業 ← closed_days.txt:N` のように表示されれば OK。
`promo` スロット（`respect_closed_days: false`）は休業日でも投稿予定のまま表示されます。
